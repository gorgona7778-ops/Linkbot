# ДВИЖ · ЛИНК БОТ

Готовый проект для Railway. По /start, /links или /help в личном чате отправляет приложенную фотографию, оформленную подпись и четыре красные URL-кнопки. Фото включено в assets/banner.jpg. Ссылки уже заполнены.

## Запуск с iPhone

1. В Telegram открой @BotFather → /newbot. Создай бота и скопируй токен.
2. Скачай ZIP и распакуй в приложении «Файлы».
3. На github.com создай приватный репозиторий. Через Add file → Upload files загрузи содержимое распакованной папки. В корне репозитория должны лежать main.py, config.json, Dockerfile и railway.json. Фото должно быть по пути assets/banner.jpg. Сам ZIP загружать вместо файлов нельзя. Если с телефона не удаётся загрузить папку assets, создай её через Add file → Create new file (имя assets/.gitkeep), затем открой assets и загрузи banner.jpg туда.
4. В Railway создай New Project → Deploy from GitHub repo → выбери этот репозиторий.
5. Открой сервис → Variables → добавь BOT_TOKEN со значением из BotFather. Подтверди изменения и запусти Deploy. Если первый запуск был без токена и завершился ошибкой, после добавления переменной сделай Redeploy.
6. Start Command уже указан: python main.py. Оставь одну реплику. Для постоянного polling выключи Serverless/App Sleeping, если такая настройка включена. Домен, порт и публичный HTTP-доступ этому боту не нужны.
7. В логах успешного запуска появится Bot started. Polling active. Открой бота в Telegram и отправь /start.

Токен хранится только в Railway Variables. Не добавляй его в GitHub или в переписку. Для работы Railway должны быть доступны ресурсы аккаунта; проект не отменяет тарифы и лимиты хостинга.

## Оформление и изменения

В config.json можно менять подпись и ссылки. Используются жирный заголовок, курсив и читаемые подписи кнопок. Telegram не поддерживает загрузку собственного шрифта для обычных inline-кнопок. Красный цвет задан официальным параметром style: danger; отображение зависит от версии клиента и темы. При необходимости обнови Telegram.

Для замены фотографии обнови assets/banner.jpg и сделай Redeploy. При изменении config.json также нужен новый деплой. Старые отправленные сообщения автоматически не редактируются — открой новое меню командой /start.

## Проверка и ограничения

Проверены локально: сборка multipart-запроса с фотографией, точность ссылок и цвета кнопок, обработка команд. Живой запуск в Telegram/Railway требует твоего BOT_TOKEN и доступа к Railway и здесь не выполнялся. Сокращённые ссылки включены ровно как присланы; их конечные адреса не проверялись.

Проект использует стандартную библиотеку Python без сторонних пакетов. Не запускай второй экземпляр с тем же токеном: Telegram допускает один polling-процесс. При ошибке 409 останови второй экземпляр. При ошибке 401 проверь BOT_TOKEN.
